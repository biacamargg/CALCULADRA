# 🧮 CALCULADRA

## 📌 Sobre o projeto

A **CALCULADRA** é uma calculadora desenvolvida com **HTML, CSS e JavaScript**, criada como projeto prático para aplicar os conhecimentos estudados no GitHub Foundations.

## 🎯 Objetivo

O objetivo do projeto é desenvolver uma aplicação simples e funcional, utilizando boas práticas de organização e versionamento com Git e GitHub.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## ⚙️ Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- 🔄 Limpeza da calculadora
- 📱 Interface simples e fácil de utilizar
